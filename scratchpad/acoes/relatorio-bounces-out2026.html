Fase 4 — Tipos de Bloqueio Identificados

Tipo 1 — Conta bloqueada Microsoft (AS42004)
550 5.1.8 Access denied, bad outbound sender AS(42004)
✓ Ação imediata: security.microsoft.com/restrictedentities → solicitar remoção
→ Prevenção: rate limit 5 min + serviço dedicado para campanhas
Tipo 2 — Blacklist SPFBL
550 5.7.1 (via spfbl.net)
✓ Ação: http://spfbl.net/en/feedback → solicitar remoção do domínio
→ Pendente para dominanttec.com.br
Tipo 3 — DNS sem registros A/MX (spamblock.cloud, MagicSpam)
550 Sender (dominanttec.com.br) has no A, AAAA, or MX DNS records
✓ Ação: configurar registros A, MX, SPF e DKIM no painel do registro.br
→ Verificar em: mxtoolbox.com — digitar dominanttec.com.br
Tipo 4 — MX remetente ausente (chkuser)
sorry, can't find a valid MX for sender domain (chkuser)
✓ Ação: mesma do Tipo 3 — configurar MX no DNS
Tipo 5 — PTR incorreto (rDNS)
550 5.7.363 Verification failed — PTR record misconfigured
⚠ Ação imediata: sem solução pelo Office 365 (IP é da Microsoft)
→ Solução definitiva: migrar para Resend, Brevo ou SendGrid (IP dedicado com PTR configurável)
