## Frameworks extraídos

### 3 Padrões dos melhores vendedores

1. **Ambição + Inconformismo** — Motor que faz tudo girar. O inconformado não precisa de chefe, campanha, nem reunião motivacional. Age por força interna.

2. **Perguntar antes de argumentar (SPIN Selling)**
   - **S — Situação:** qual é o contexto atual do cliente?
   - **P — Problema:** o que está travando, o que incomoda?
   - **I — Implicação:** quanto esse problema está custando? O que acontece se não for resolvido?
   - **N — Necessidade:** convide o cliente a imaginar como seria diferente se o problema fosse resolvido.
   - A pergunta certa faz o cliente vender para ele mesmo.

3. **Resiliência à rejeição** — Os melhores não recebem menos "não" — se recuperam mais rápido. Separar: o "não" é sobre aquela oportunidade específica, naquele momento, não sobre quem você é.

### O script como mínimo obrigatório
> "O script não é o que você fala. É o que você não pode deixar de fazer."
> 
> O bom vendedor improvisa em cima de um mínimo obrigatório, não no vazio. O script existe para os dias ruins, para os momentos de pressão — não para os dias bons.

### "Sofrer compra" vs fazer venda
Quando o cliente conduz a conversa, define preço e ritmo → você está sofrendo compra. O número pode fechar no mês, mas você não está vendendo. Você está administrando o que o cliente decidiu.

### A pergunta do "por quê"
Nunca aceite uma objeção de preço/orçamento sem perguntar: **"Por que esse é o seu orçamento?"** O número pode ser um chute, um orçamento antigo não revisado, ou uma tentativa de negociação. Nunca saberá se não perguntar.

### Feedback é prato que se come quente
Feedback dado uma semana depois perdeu metade do valor. Tem que ser rápido. A ferramenta de análise só funciona se existir um script e um padrão antes — sem padrão, o relatório não diz nada.
